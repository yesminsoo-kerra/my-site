# 사이트 설계도(PRD) — (미정: 아나운서·MC 이름)

작성일: 2026-10-10 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
행사·축제·포럼·토론회를 진행하는 아나운서·MC·사회자의 레퍼런스와 경력을 보여 주고, 섭외 문의를 받는 사이트.

## 2. 손님
- 누가: 행사·축제·포럼·토론회에 아나운서·MC·사회자를 섭외하는 기관·기업 담당자
- 어디서 알고 오나: 지인·기관 소개, 네이버·구글 검색, 인스타·유튜브·블로그

## 3. 손님이 궁금한 것 (연락하기 전에)
1. 우리와 비슷한 행사(축제·포럼·토론회)를 진행해 봤는지 — 경력
2. 출연료·비용은 어떻게 되는지
3. 그날 가능한지, 우리 지역까지 오는지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 진행 사진
- 진행 영상
- 행사 경력 목록 (언제 · 어느 기관 · 어떤 행사)
- 기관 후기·추천 (실제로 받은 문구만, 기관명 표기는 허락받은 것만)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 섭외 문의하기
- 누르면: 문의 폼

## 6. 페이지 구성 (위에서 아래로)
1. 첫 화면 — 한 문장 + 진행 사진 + [섭외 문의하기]
2. 진행 영상 — 실제 진행 모습 (목소리·진행 스타일)
3. 행사 경력 — 축제 · 포럼 · 토론회 등 종류별 목록
4. 진행 사진 모음
5. 기관 후기·추천 (실제 받은 것만)
6. 섭외 안내 — 활동 지역: 전국 가능 / 출연료: 문의 시 안내
7. 문의 폼

## 7. 문의 폼에서 받을 것
- 담당자 이름, 연락받을 이메일
- 행사 지역
- 행사 날짜
- 기관명
- 개인정보 수집·이용 동의 (필수)

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 출연료는 공개하지 않음 — "행사 규모와 시간에 따라 달라요. 문의해 주시면 안내드려요."
- 시간: (미정)
- 위치: 전국 가능
- 연락 방법: 사이트 문의 폼 (답장은 담당자가 남긴 이메일로)
- 이름·직함(아나운서/MC/사회자 표기): (미정)

## 9. 이번에 넣지 않을 것
- 회원가입·로그인
- 결제
- 출연료 표·금액 공개
- 일정 달력(가능한 날짜 실시간 표시)
- 알림 메일 (문의가 오면 메일로 알려 주기)

## 10. 첫 화면 한 문장 후보
1. 행사의 처음과 끝을 책임지는 진행자, (이름)입니다.
2. 축제부터 포럼·토론회까지, 행사에 맞는 목소리로 진행합니다.
3. 전국 어디든, 행사의 흐름을 안정적으로 이끕니다.

## 11. 다음에 할 것
- 진행 영상·사진·경력 목록·후기 원본 모으기 (사이트에 넣을 실제 자료)
- 이름·직함·프로필 사진 정하기
- 문의 알림 메일, 가능 일정 표시는 필요해지면 추가

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 고급스러운 · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 예 → Supabase(leaderpl-admin 스킬) + /admin
- 회원가입: 이번엔 아니요
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
3. 문의 폼 → Supabase 저장 → /admin 관리자 페이지까지 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 관리자 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제, 관리자 비밀번호(ADMIN_PASSWORD) 입력
